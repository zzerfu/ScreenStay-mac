1.2.3

最新稳定版 2026-11-04 · Build 6

修复

  • 修复音乐暂停后，菜单栏仍显示播放中、绿点不消失、电源断言继续持有的问题。
  • 修复部分播放器暂停后 kMRMediaRemoteNowPlayingInfoPlaybackRate 仍停留在 1 的误判。

变更

  • 新增内置 Perl 辅助器：nowplaying-probe.pl 与 libScreenStayNowPlaying.dylib。
  • 通过 /usr/bin/perl 调用 MRMediaRemoteGetNowPlayingApplicationIsPlaying，取得真实播放/暂停状态。
  • JXA 只负责读取应用名、标题、PID 和 Bundle ID；Perl 不可用时回退到 PlaybackRate、进程音频输出和 isCurrentlyPlaying。
  • 严格模式暂停释放延迟缩短到约 1–3 秒。
  • --nowplaying 增加 perlAvailable、perlIsPlaying、pid、bundle 等输出。

验证

perlAvailable=true
perlIsPlaying=false
source=jxa
isPlaying=false
playbackRate=0.0

暂停后电源断言释放，绿点消失；播放时 perlIsPlaying=true，断言正常创建。

1.2.2

2026-11-04 · Build 5

修复

  • 修复严格模式下无法识别实际播放状态、菜单栏绿点不出现。
  • 绕开 macOS 15.4+ 对第三方 App 的 MediaRemote 状态限制。

变更

  • 使用 /usr/bin/osascript 执行 JXA 辅助脚本，读取 MRNowPlayingRequest.localNowPlayingItem。
  • 以 PlaybackRate 判断播放，修复旧 C 接口固定返回 Paused 的问题。
  • --nowplaying 增加 source=jxa、isPlaying、playbackRate 等输出。
1.2.2 解决了“检测不到播放”的问题，但暂停时某些播放器仍会保留 Rate=1，因此后续在 1.2.3 增加了 Perl 真实状态确认。

1.2.1

2026-11-04 · Build 4

过渡修复

  • 旧 C 接口被限制后，改用 Objective-C 桥接 MRNowPlayingRequest。
  • 新增 --nowplaying 诊断命令。

结果

能读取播放应用名称，但 macOS 27 上 localIsPlaying 与 localPlaybackState 仍返回过期的 Paused。该版本作为过渡记录保留，建议使用 1.2.3。

1.2.0

2026-11-04 · Build 3

新增

  • 右键菜单新增“仅系统媒体播放时触发”，默认开启。
  • 严格模式只监听 macOS 右上角 Now Playing，普通提示音不会触发。
  • 关闭严格模式后回退到 Core Audio + Now Playing 兼容模式。
  • 开关状态持久化到 UserDefaults。

已知问题

受 macOS 15.4+ 权限限制，严格模式实际无法识别播放，绿点不出现；已在 1.2.2 / 1.2.3 修复。

1.1.0

2026-11-03 · Build 2

新增

  • 右键菜单新增“其他影响熄屏的应用”。
  • 通过 IOPMCopyAssertionsByProcess 读取 NoDisplaySleepAssertion 与 PreventUserIdleDisplaySleep。
  • 自动排除 ScreenStay 自己，按应用合并进程，悬停显示 PID 与断言类型。
  • 新增 --blockers 诊断命令。

1.0.0

2026-11-03 · Build 1

首次发布

  • 原生 macOS 菜单栏 App，无 Dock 图标；单击开关，右键菜单。
  • Core Audio 输出 + Now Playing 检测，媒体停止后延迟释放。
  • 创建 PreventUserIdleDisplaySleep 与 PreventUserIdleSystemSleep。
  • SMAppService 开机自启；通用二进制；自定义图标；DMG / ZIP 安装包。
  • 无需辅助功能、屏幕录制或麦克风权限；不联网、不上传数据。

02升级建议

从任意旧版本升级，请使用 1.2.3。 如果之前注册过开机自启，移动 App 到 Applications 后，建议在右键菜单中关闭再重新打开一次“开机自启”。

升级不会清除已有偏好设置：总开关、严格模式、登录项状态都会保留。
