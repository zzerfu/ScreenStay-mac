ScreenStay · 使用说明

让屏幕在该亮的时候
保持清醒

ScreenStay 是一个常驻 macOS 菜单栏的小工具：音乐或视频播放时阻止屏幕休眠，暂停后自动释放。它只关心系统播放列表，不会被零散的提示音打扰。

v1.2.3 · 稳定版 macOS 13+ 无追踪

01概览

默认的严格模式只认可 macOS 右上角“正在播放”列表中的媒体。音乐或视频开始时，ScreenStay 创建一个防熄屏断言；暂停或结束后，断言会在 1–3 秒内释放。

系统

macOS 13 及以上

架构

Apple Silicon + Intel

权限

无额外系统权限

当前版本 1.2.3。 使用系统 Perl 读取真实的 Now Playing 播放状态，解决了 macOS 15.4+ 上第三方 App 查询接口返回过期 Paused 的问题。

02功能

只看系统播放列表

严格模式不采样普通音频输出，连续提示音、点击音效和后台声音不会触发。

暂停即释放

读取真实播放状态与播放器进程音频输出，暂停后 1–3 秒内释放电源断言。

菜单栏即开关

单击图标立即开启或关闭；右键打开菜单，查看状态、开机自启和影响熄屏的其他应用。

安静的电源断言

只在需要时创建 PreventUserIdleDisplaySleep 与 PreventUserIdleSystemSleep。

开机自启

通过 SMAppService 注册登录项，可在系统设置中批准或撤销。

不联网

没有账号、遥测或云端请求；所有判断都在本机完成。

03安装

把 App 放进“应用程序”文件夹并打开即可。第一次打开时，菜单栏会出现一个显示器图标。

下载 DMG 下载 ZIP 查看更新记录
  1. 双击 DMG，把 ScreenStay 拖入 Applications。
  2. 打开 ScreenStay，允许它出现在菜单栏。
  3. 需要开机启动时，右键图标并勾选“开机自启”。
如果 Gatekeeper 拦截，请在“系统设置 → 隐私与安全性”中选择“仍要打开”，或执行 xattr -dr com.apple.quarantine /Applications/ScreenStay.app。

04使用

操作效果
单击菜单栏图标立即开启或关闭防熄屏
右键 / Control + 单击打开设置菜单
菜单 → 保持屏幕常亮总开关，与单击图标等价
菜单 → 仅系统媒体播放时触发严格模式开关，默认开启
菜单 → 开机自启注册或取消登录项

开启保护且媒体正在播放时，图标右侧会出现绿点；关闭开关后图标变暗，不再干预屏幕休眠。

菜单中的“其他影响熄屏的应用”会列出持有 NoDisplaySleepAssertion 或 PreventUserIdleDisplaySleep 的其他进程。macOS 会汇总所有应用的断言，ScreenStay 无法取消别人的防熄屏请求。

05检测原理

严格模式使用两层只读查询，避免只凭播放速率或静音音频流误判：

  1. 系统 Perl 辅助器：通过 /usr/bin/perl 加载内置的极小 dylib，调用 MRMediaRemoteGetNowPlayingApplicationIsPlaying，取得真实的播放/暂停状态。
  2. JXA 辅助脚本：通过 MRNowPlayingRequest 读取应用名、标题、PID 和 Bundle ID，用于菜单展示。
  3. 电源断言：确认播放后创建 PreventUserIdleDisplaySleep 和 PreventUserIdleSystemSleep。
  4. 回退检测：Perl 不可用时，使用 PlaybackRate、播放器进程音频输出和 isCurrentlyPlaying 组合判断。
macOS 15.4 之后，普通第三方 App 直接调用 MediaRemote C 接口会得到过期的 Paused。ScreenStay 不申请辅助功能、屏幕录制或麦克风权限，而是使用系统 Perl 作为受信任的读取进程。

06诊断

App 内置命令行诊断，不需要打开菜单：

# 观察 10 秒检测状态与电源断言
/Applications/ScreenStay.app/Contents/MacOS/ScreenStay --diagnose 10

# 查看当前影响熄屏的其他应用
/Applications/ScreenStay.app/Contents/MacOS/ScreenStay --blockers

# 查看系统 Now Playing 状态
/Applications/ScreenStay.app/Contents/MacOS/ScreenStay --nowplaying

# 查看 / 开启 / 关闭登录项
/Applications/ScreenStay.app/Contents/MacOS/ScreenStay --login-status
/Applications/ScreenStay.app/Contents/MacOS/ScreenStay --enable-login
/Applications/ScreenStay.app/Contents/MacOS/ScreenStay --disable-login

播放音乐时，--nowplaying 应显示 perlIsPlaying=true；暂停后变为 false，同时电源断言释放。

07隐私与权限

  • 不联网、不上传播放记录或设备信息。
  • 不需要辅助功能、屏幕录制或麦克风权限。
  • 只读访问 macOS 的播放状态与进程音频状态。
  • 菜单栏中的“影响熄屏的应用”只在本机读取电源断言。
  • 偏好设置保存在本机 UserDefaults 中。

08从源码构建

需要 macOS 13+ 与 Command Line Tools：

cd ScreenStay
./build.sh
open ScreenStay.app

构建脚本会编译 arm64 与 x86_64、合并通用二进制、打包内置 Perl 辅助器，并在临时目录完成 ad-hoc 签名。

重新生成安装包：

./package.sh

09卸载

  1. 右键菜单栏图标，取消“开机自启”。
  2. 选择“退出 ScreenStay”。
  3. 删除 /Applications/ScreenStay.app。
  4. 可选：执行 defaults delete com.zzerfu.ScreenStay 清理偏好设置。
